# Обновление привязки и повторная проверка

По поручению пользователя привязка обновлена до точной новой контрольной суммы. Повторный полный набор программных проверок завершён успешно; журналы и точная версия сохранены в threshold-correction/pin-update. Модель и формулы совпадают с прежними по контрольным суммам. Старые и посторонние изменения преобразователя отклоняются.

Исходная версия: 9850f667be786dfb7b1c553b21f6a056e4b1a1c7. Полная команда, сведения об окружении, результат, контрольные суммы модели и формул находятся в results.json. Сборка создаёт 50 процессов и 81 формулу согласно проверкам проекта. Проверка свойств в UPPAAL не выполнялась. Исторический перечень исходников не изменён: загрузчик содержит явную замену одной точной суммы, с проверкой её происхождения.
