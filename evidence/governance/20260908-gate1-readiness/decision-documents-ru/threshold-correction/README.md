# Исправление восьми пороговых расхождений

По прямому поручению пользователя от 10.09.2026 исправлены преобразователь и документы №02–05. Разрешённый объём текущего изменения: src/uppaal_mcp/phy/alpha.py, tests/test_phy_threshold_boundaries.py и decision-documents-ru/** в задаче подготовки №21. Это уточнение поручения не означает, что область существующей задачи GitHub была изменена или результат принят проверяющим.

Источник кода и документов: ветка codex/artmus208/21-threshold-decision, исходный commit ff54693c4c0afe8886efb6b124bb95672e2b56a6. Реализация проверена на commit, указанном в check-results.json.

Правило: для растущих показателей качества нижний интервал включает порог (<=); для растущих показателей неблагополучия верхний интервал включает порог (>=). Значения вне точных равенств не меняются. Проверяются ближайшие представимые числа с обеих сторон восьми порогов (24 случая), 12 внутренних значений и 3 случая отдельно заданного предела возраста.

Это программная проверка преобразователя, не проверка свойств объединённой модели в UPPAAL. Исторические отчёты P1 сохраняют прежние результаты и не переписываются. Физическая калибровка, отсутствующие данные и научная оценка комиссией конференции не подтверждаются этим исправлением. Gate 1 не объявляется пройденным.

Полные команды и коды завершения находятся в check-results.json, вывод — в файлах thresholds.* и full.*. Обновлённые документы №02–05 различают принятое пользователем правило, выполненное исправление и ожидаемую независимую приёмку.

Результат: 3 проверки преобразователя успешны (24 граничных, 12 внутренних и 3 случая изменённого предела). Общий набор: 131 проверка, 2 ошибки — истечение времени запуска сервера и отказ сборки из-за изменённого закреплённого исходника alpha.py. Обновление привязки и повторная приёмка объединённой модели ещё требуются.
