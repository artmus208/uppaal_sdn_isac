# Проверки дополнения

Машинная запись команд, Python/OS, source commit и exit codes — [checks.json](checks.json).
stdout/stderr хранятся рядом. Это software/static validation, не UPPAAL evidence.

| Команда | Назначение |
|---|---|
| `python3 -B evidence/validation/20260917-v03-timing/audit.py` | Восстановить 43 строки/14 полей из pinned inputs, сравнить generated bytes, значения layer/boundary constants и hashes |
| `python3 -B evidence/validation/20260917-v03-timing/check_audit.py` | Четыре проверки: исходный пакет принимается; изменённый XML, отсутствующий integration contract и испорченный generated output отклоняются |
| `python3 -B scripts/check_coordination.py` | Структурная проверка общих coordination artifacts |
| `git diff --check` | Отсутствие whitespace errors в текущем diff |

Негативные проверки используют подмену чтения в памяти; исторические файлы не
изменяются. Они проверяют отказ аудитора при порче материалов, а не timed behavior.

Полный программный набор и диагностические прогоны PR #31 не повторялись:
production, tests, модель и queries не изменены; нового расхождения в принятом
MAC ACK исправлении не найдено. В этом дополнении новый исполняемый код — только
локальный static auditor и его проверки. Независимые прежние результаты и их
полный provenance доступны в
[review #31](https://github.com/artmus208/uppaal_sdn_isac/pull/31#issuecomment-5715834670).

Read-only audit не обосновывает корректность человеческой интерпретации contracts.json;
это предмет независимого review. Полные ACK/recovery/admission свойства и
обязательное завершение на time-stopped трассах не заявляются проверенными.

Публикация: обычный HTTPS git push первоначально завершился с
`fatal: could not read Username for 'https://github.com': No such device or address`.
Для публикации используется подключённый GitHub от имени carwasher. Локальные
checkpoint commits сохраняются отдельно; точный опубликованный HEAD указывается
в PR. Дерево публикации сверяется с локальным результатом.
