## Что уточнено

- Разделены абстрактные параметры исследования и физическая калибровка конкретной
  аппаратуры. Условные единицы времени допустимы для заявленной абстрактной модели.
- Определены вероятность обнаружения, вероятность и интенсивность ложных тревог,
  условия применимости CA-CFAR, единицы SINR и смысл статистических оценок.
- Уточнены модуль ошибки, ограничения CRB, определение sensing capacity,
  совместно используемое время, перегрузка и диапазоны штрафов.
- Разобраны пороговые границы, отсутствие измерений, возраст исходной информации,
  роли 12 PHY-констант времени и 28 конечных PHY-доменов.
- Предлагаемые физические интерпретации отделены от фактически реализованных
  преобразований. Новых эмпирических данных и результатов model checking нет.

- [validation-report.md](validation-report.md) — исправленная редакция.

- [validation-report.phy-revision-20260910.json](validation-report.phy-revision-20260910.json) — исходная запись локальной проверки; её результаты отделены от нового запуска ниже.
- [check_publication.py](check_publication.py) — проверка хешей, воспроизведения patch, ссылок и write scope.
- [run_checks.py](run_checks.py) — запись команд из CONTRIBUTING с stdout/stderr и кодами выхода.

Из корня репозитория:

```bash
python evidence/validation/20260910-phy-revision/check_publication.py
python evidence/validation/20260910-phy-revision/run_checks.py --output-dir /tmp/phy-report-review-unique-run
```

Вторая команда требует отдельного установленного окружения по CONTRIBUTING.md
и свободного каталога результатов; она не перезаписывает сохранённые проверки.
Возврат 1 означает, что хотя бы одна команда завершилась ошибкой, включая
проверку доступности verifier; точная причина записывается в `checks.json`.
Проверки публикации и software tests не доказывают физическую адекватность
формул, выполнение свойств модели или прохождение Gate 1.

Первичная проверка `git diff --cached --check` сообщила 27 предупреждений о
конечных пробелах внутри сохранённого unified patch. Это строки контекста,
состоящие из обязательного пробела, обозначающего неизменённую пустую строку.
Локальный `.gitattributes` отключает только `blank-at-eol` для этого одного
patch-файла, чтобы сохранить его исходные байты; остальные файлы и виды
проверок остаются под стандартной проверкой whitespace.
