# Interpretation and return condition

This diagnostic changes only the predeclared search traversal. Its question is
whether the bounded run obtains a witness for each *existing* service query.
A timeout neither disproves reachability nor establishes the shared resource is
exercised. The model allows optional service and absorbing overflow; even a
positive grant witness would not establish useful departure or fairness.

Static reading explains two prerequisites: the target queue must already be
nonempty and its MAC scheduling mode must be COMM or JOINT at a service epoch.
All queues start empty and scheduling starts IDLE. The first load update cannot
select a service opportunity from an empty queue. These facts come from the
SharedLoad selector and initial declarations; they are not a reachable-state
proof that a later grant is possible or impossible. No symmetry inference is
used because notification order is fixed by entity index.

After the fixed ten attempts, an unresolved query stays open under plan v2 §1.1.
Do not repeat the campaign, sweep seeds, increase limits, weaken queries or
modify a model within this deliverable. A justified later task could construct
and replay an exact witness on the full unchanged model, or the Integrator could
explicitly narrow the proposed P4 claim so it does not assume unresolved service
nonvacuity. Either option needs its own decision and scope. The full P4 series
still requires independent family/query/protocol acceptance and a new Gate 1.
No R03/R04/C06 closure, P3 transfer or arbitrary-N statement follows here.
