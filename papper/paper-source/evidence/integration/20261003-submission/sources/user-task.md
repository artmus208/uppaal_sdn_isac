Для ещё не использованной серии #89 этим заданием разрешаю материализацию
опубликованного Hnom и одну серию шести запросов на подготовленном Windows
checkpoint 77c0431049e4b5d367d56e1eb5232ed2d330258e после технической проверки
протокола агентом. Сохраняются все шесть формул и исходная M; Hnom остаётся
диагностическим ограничением окружения, не доказанной моделью надёжного сервиса.
Один verifier, без повторов; пределы поиска 180/180/180/600/180/180 секунд,
1500 секунд суммарно и максимум 1800 секунд всей сессии. Порог памяти —
min(50% фактической RAM, 8 GiB), по подготовленному native monitor/watchdog.
Error, monitor/watchdog failure или превышение общего бюджета останавливают
серию по существующему протоколу. Новые формулы, увеличение лимитов и повторы
не разрешены. Не начинай, если ledger показывает использованные попытки
или найден активный Runner; разбирай уже существующие результаты.
