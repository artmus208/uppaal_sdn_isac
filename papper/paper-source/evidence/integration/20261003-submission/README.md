# MoNeTec-2026 — комплект редакции от 3 октября 2026

Основная статья собрана в Springer proceedings: **15 страниц PDF**. Word содержит
тот же текст, формулы, таблицы, рисунки и библиографию; LibreOffice разбивает его
на **16 страниц**. Авторская научная проверка и подача остаются за авторами.

## Основные файлы

- `MoNoTeC-2026-paper.pdf` — PDF из основной TeX-редакции, в том числе для экспертизы ИТМО.
- `MoNoTeC-2026-paper.docx` — редактируемый Word из той же редакции.
- `reviewer-response.pdf`, `reviewer-response.docx`, `reviewer-response.md` — один point-by-point ответ на три рецензии.
- `levels_tex/samplepaper.tex` и `monotec2026.bib` от корня репозитория — основные исходники.
- `AUTHOR-HANDOFF.md` — оставшиеся действия автора и подтверждённые сведения об экспертизе/подаче.
- `EVIDENCE-INDEX.md` — связь научных утверждений с конкретными моделями и сохранёнными результатами.
- `checks/FINAL-CHECKS.md` — проверка сборки, документов и ограничения.
- `MoNoTeC-2026-source.zip` — переносимый комплект исходников, документов и отобранных исходных evidence.
- `MoNoTeC-2026-full.bundle` — полная восстанавливаемая Git-история рабочей ветки.
- `RELEASE.json` — итоговый commit, контрольные суммы документов и архивов.

Архивы и RELEASE.json создаются после заключительного commit и не включаются
сами в себя. Windows-копия комплекта находится в каталоге `RESULT-92` рядом с
исходным `START-CODEX.md`. Папка `paper-source` сохраняет относительную структуру
TeX, библиографии, стилей и рисунков. ZIP дополнительно содержит выбранные raw evidence.

## Сборка из исходников

Распаковать ZIP с сохранением путей. Главный файл — `levels_tex/samplepaper.tex`,
а не старый корневой `main.tex`. В установленном TeX Live с `latexmk`, BibTeX и
Latin Modern выполнить из распакованного корня:

```bash
bash evidence/integration/20261003-submission/sources/build-paper.sh
```

Скрипт сам задаёт пути к приложенным `llncs.cls`, `splncs04.bst` и библиографии.
Повторная сборка статьи **не запускает верификатор**. При сборке через другой TeX
редактор задать эти же TEXINPUTS/BSTINPUTS/BIBINPUTS. Копии стилей взяты из
существующего Springer-экспорта проекта; `llncs.cls` имеет версию 2.24.

Для Word/рисунков нужен Python с зависимостями из `sources/artifact-requirements.txt`
и Pandoc 3.9 (он входит в указанную версию pypandoc_binary). Сначала при необходимости
перегенерировать рисунки первой командой ниже, затем собрать PDF приведённым выше
скриптом, чтобы получить окончательные AUX/BBL. После этого выполнить оставшиеся команды:

```text
python evidence/integration/20261003-submission/sources/make_figures.py
python evidence/integration/20261003-submission/sources/render_pdf.py
python evidence/integration/20261003-submission/sources/make_word.py
python evidence/integration/20261003-submission/sources/make_response.py
```

`make_figures.py` проверяет SHA256 исходного S XML; модель не изменяется.
На Windows шрифт рисунков — системный Arial, на Linux предусмотрен DejaVu Sans.
Шрифты встроены в PDF. PNG 800 dpi нужны для Word; формулы остаются Office Math,
таблицы — нативными таблицами. Раскладка Word может зависеть от приложения.

Финальная проверка использовала установленный LibreOffice, Poppler и штатный
`render_docx.py` skill documents через `sources/render_word.py`. Последний
устраняет только ошибку очистки временного каталога Windows updater; ошибки
конвертации/отрисовки не подавляются. Для повторения вне Codex можно конвертировать
DOCX штатным LibreOffice и визуально проверить его PDF.

Чтобы восстановить рабочую ветку полностью:

```text
git clone MoNoTeC-2026-full.bundle monotec-restored
```

Ветка локальная; канонический репозиторий не был слит или переписан. Полный bundle
позволяет перенести и опубликовать именно сохранённую историю без зависимости от
доступности текущего рабочего каталога.
